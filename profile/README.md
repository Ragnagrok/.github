## Ragnagrok

Software engineering when the code is written by machines: types, laws, properties and models
that hold no matter who, or what, wrote the code.

Every article on [blog.ragnagrok.com](https://blog.ragnagrok.com) that makes a claim you can check
comes with a repo that checks it. Each one has a `check.sh` that builds what should build, rejects
what should be rejected, and fails where the article says it fails.
